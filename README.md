# Blogify

A full-stack blogging application built using React, Node.js, Express.js and MongoDB.

## Tech Stack

### Frontend
- React
- React Router
- Tailwind CSS
- Axios

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- Multer

## Features

- User authentication
- Create blogs
- View all blogs
- View individual blogs
- Upload blog cover images
- Comment on blogs
- MongoDB database
